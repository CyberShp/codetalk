# F001 GraphSearch UI (Superseded)

F001 described an always-dark, GraphSearch-centric product direction. That direction conflicts with the current CodeTalk product: a light-by-default testing workbench with workspaces, AI threads, workflow orchestration, evidence and downloadable test artifacts.

The active product does not expose a GraphSearch page and does not depend on this Feature. Relevant source navigation is handled through workspace source slices, GitNexus/CGC evidence and Workbench execution. F001 is archived and must not be returned to `BACKLOG.md` without a new product proposal and acceptance criteria.
