# Legacy DeepWiki Archive

These documents describe the removed DeepWiki integration as it existed in May 2026. They are retained only for historical diagnosis and must not be used as deployment or product guidance.

Current behavior:

- CodeTalk no longer installs, starts, probes or links to DeepWiki.
- Source understanding uses workspaces, GitNexus, optional CGC, AI threads and Workbench workflows.
- Current deployment instructions are `docs/DEPLOYMENT.md` and `docs/LOCAL_DEPLOYMENT.md`.

Archived handoffs may contain obsolete ports, routes, Windows paths and launch commands. None are release requirements.
