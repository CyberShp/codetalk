# Step 05：多源场景增殖和风险解释

## 目标

从实现事实演绎场景，并向测试人员解释每个风险为什么存在。

## 必须输出

- `活文档/13-场景候选池与推导说明.md`
- `活文档/14-风险点清单与因果说明.md`
- Step 05 Coverage Gate

## 场景候选池

先按八类驱动源分别总结发现，再列候选：

- 分支；
- 状态；
- 资源和不变量；
- 数值/N/2N/翻转；
- 并发；
- 异常传播；
- 需求/协议/安全/配置；
- 覆盖率和历史证据。

每个候选必须解释从哪段实现事实推导出来，不能只列名称。

## 风险点

每个风险用因果叙述：

```text
什么条件发生
→ 代码内部哪里失效
→ 状态/资源/数据留下什么问题
→ 为什么当前操作可能仍看似正常
→ 什么时候对外暴露
→ 黑盒如何证明
```


## 目录限制

本步骤只写入 `活文档/` 和 `内部索引/`，不得写入 `正式输出/`。
