# Step 09：正式交付

## 目标

从已通过独立审查的 Markdown 活文档生成最终交付。

## 只允许在本步骤写入 `正式输出/`

必须生成：

1. `正式输出/开发给测试讲代码.md`
2. `正式输出/流程分支状态资源与异常传播.md`
3. `正式输出/风险点与SFMEA.md`
4. `正式输出/黑盒测试场景.md`
5. `正式输出/黑盒测试流程.md`
6. `正式输出/黑盒测试用例.md`
7. `正式输出/覆盖审计与分析限制.md`
8. `正式输出/完整分析报告.md`

## 禁止

- 正式输出中出现 `01-`、`02-` 等步骤编号文件；
- 将范围契约、证据消费记录等过程文件复制到正式输出；
- 创建正式输出子目录；
- 用 JSON 代替 Markdown；
- 重新凭记忆写一套与活文档不一致的结论。

完整分析报告应包含必要的范围和证据摘要，但不需要把过程文档原样作为独立正式文件。
