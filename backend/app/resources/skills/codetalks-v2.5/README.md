# Codetalks

Codetalks 是一个面向黑盒测试人员的源码驱动测试分析 Skill。

它要求 Agent 先像熟悉模块的开发人员一样读懂代码，讲清楚：

- 模块和流程是干什么的；
- 外部操作如何进入代码；
- 正常流程怎样运行；
- 各个分支在什么条件下进入；
- 状态和内部资源如何变化；
- 超时、并发和异常如何传播；
- 存在哪些边界、资源、翻转、恢复和安全风险；
- 黑盒测试应如何构造、观察和判定。

Skill 支持：

- 模块全量测试分析；
- 问题单和 MR 回归分析；
- 问题、日志与代码根因辅助定位；
- 资源泄漏、计数翻转、并发、恢复、性能和高可用等专项分析。

分析过程使用 Markdown 活文档持续记录，JSON 只用于内部运行状态。最终输出包含开发实现讲解、SFMEA、黑盒测试场景、测试流程、测试用例和覆盖审计。

运行目录固定为：

```text
<运行根目录>/
├── 活文档/      # 包含任务交接和分析过程文档
├── 内部索引/    # 仅运行状态和恢复索引
└── 正式输出/    # 仅最终交付
```

安装时必须保留整个 Skill 目录，包括 `steps/`、`references/`、`templates/`、`checklists/` 和 `scripts/run_guard.py`。
